# GovFix Civic

A Next.js civic service desk demo for reporting, tracking, and resolving municipal issues.

## Run locally

### Requirements

- Node.js 20 or newer
- pnpm 9 or newer

### Development server

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server reloads automatically when files change. Stop it with `Ctrl+C`.

### Production build

```bash
pnpm build
pnpm start
```

The production server is also available at [http://localhost:3000](http://localhost:3000).

This project is self-contained and does not require environment variables or an external service to run locally.
